# 📖 详细使用说明

## 1. 选择用药类型

主界面左侧「🧪 用药类型」面板点击类型卡片即可。内置「杀菌」「果蝇」两种，可自定义增减：
- **＋ 新建类型**：填写名称/图标/每亩水量/一套药需水量/省药系数等，保存后立即可用
- **✏️ 编辑当前**：修改选中类型的参数
- **↺ 找回默认**：一键找回被删除的杀菌/果蝇
- 选中类型后自动加载：建议飞行高度、每亩水量、每亩棵数 & 每棵水量、一套药需水量、省药系数
- 旧版本存的作物（果树/水稻等）会自动转为自定义类型，参数不丢
- 自定义类型随「导出配置」一起分享，别人导入即得

下方会显示该类型的作业注意事项。

## 2. 设置作业参数

「📋 作业参数」面板中可修改：
- **计算基准**：按亩数 / 按棵数（单卡多卡都可切换）。按棵数直接填果树棵数，亩数按 棵数÷每亩棵数 反推
- **果树棵数**：按棵数计算时的主输入
- **作业亩数**：本次需要打药的总亩数（按棵数计算时由棵数反推，输入框自动隐藏）
- **机载装药上限**：无人机药箱一次最多装载的药液量（多地块模式按此算每块地最少趟数）
- **地块模式**：单地块 / 多地块（多地块见第 12 节）
- **飞行高度**：可使用类型默认值，也可根据实际情况调整
- **每亩水量**：根据作物密度和生长期调整
- **每亩棵数 / 每棵水量**：果树类使用；按棵数计算时每亩棵数锁定只读
- **一套药需水量**：决定一套药能配多少药液
- **无人机省药系数**：0.7 表示比人工省 30%，可根据机型调整

> 💡 鼠标悬停字段名右边的 **`i`** 图标可查看该参数的详细说明。

## 3. 设置成本参数

「💰 成本明细」面板按 3 个 Tab 分类：

### 🔋 循环与油费
- **电池折旧**：每组电池每充一次电分摊的折旧费（默认 7 元/次）
- **本次油费**：满载油出发、回家加满的加油差价，直接填总数；
  系统自动算出**每次充电油钱 = 油费 ÷ 充电次数**（发电机模式下即充电油耗参考）
- **单循环亩数**：一组电池能完成的作业亩数（单地块按亩口径的成本用）

### 👥 人工
3 人团队一天可喷 30-50 亩；按天计薪时半天通常按 1 天算。

### 📦 其他
防护装备、清洗费用、其他杂费、药剂单价与包药开关等。

## 4. 设置收入

「💵 收入与药剂」面板：
- **每亩收费**：服务费单价
- **农机补贴等**：如有补贴填入

## 5. 查看结果

右侧「📊 计算结果」面板实时显示：
- 💊 药剂用量（套，含向上取整建议）
- 💧 用水量（升）
- 💰 总成本（含每亩成本）
- 📈 粗略利润（含利润率，亏损红色警示）

下方还有：
- 🚁 建议飞行高度
- 🔄 需要循环数
- 📐 每亩成本
- 💵 每亩利润

「🧮 成本汇总」表展示各成本项金额及占比条形图。

## 6. 计算按钮（触发动画）

点击「🚁 开始计算」按钮：
- 触发无人机带着药雾飞过屏幕的动画
- 把本次计算保存到历史记录
- 显示「计算完成」提示

## 7. 预设管理

### 保存预设
点击「💾 存为预设」，输入名称（如「苹果园-春季-10亩」）即可。

### 加载预设
点击「📂 加载预设」打开预设管理弹窗：
- 点击列表项加载
- **右键**点击列表项可删除

### 预设内容
预设保存当前用药类型、作业参数、所有成本和收入参数的完整快照。

## 8. 导入导出（配置分享）

### 导出
1. 点击「📤 导出」按钮
2. 切换 **📝 文本格式**（易读，带中文标记）或 **⚙️ JSON 格式**（精确）
3. 点击「📋 复制到剪贴板」
4. 发给朋友（微信、QQ、邮件均可）

### 导入
**方式 A：通过弹窗**
1. 点击「📥 导入」按钮
2. 粘贴配置文本
3. 点击「识别并填入」

**方式 B：快捷键**
- 按 `Ctrl+Shift+V`（Win）或 `Cmd+Shift+V`（Mac）直接从剪贴板读取并填入

### 支持的格式
- ✅ JSON 格式（导出时的 JSON 选项）
- ✅ 文本格式（导出时的文本选项，带【】标记）
- ✅ 自动识别，无需手动指定

## 9. 历史记录

点击「🕘 历史记录」按钮查看最近 20 次计算。
可点击「🗑 清空历史」一键清除。

## 10. 主题切换

点击右上角「☀️ / 🌙」按钮切换日间/夜间模式，自动记忆。

## 11. 打印结算单

按 `Ctrl+P` 触发浏览器打印，会自动隐藏装饰元素，生成干净的结算单（可直接打印或保存为 PDF）。

## 12. 多地块模式

「📋 作业参数」面板顶部切换「单地块 / 多地块」。多地块模式下每个地块一张卡片：

- **地块名称**：自定义（默认 地块1、地块2…）
- **亩数**：该地块打药面积（多地块固定按亩数，与棵数无关）
- **作业组**：相邻地块填相同组号即可连片连续作业（合并算趟数，组内不返航）；地块远近不在地块里单独填，统一用「时间参数」里的来回升降时间体现
- **农户**：该地块归属的农户，结算按农户分开；选择后带出档案默认单价
- **趟数（选填）**：留空 = 按机载装药上限自动算最少趟数；手动填写可凑实际每趟加药量（每趟加药量 = 地块水量 ÷ 趟数，改趟数即时重算）
- 卡片底部实时显示该地块：水量 / 最少趟 / 每趟量

结果区生成**组汇总条**（每组水量/趟数/每趟量，± 调整组趟数凑每趟加药量）和**地块明细表**（含组列、小数用量列），汇总与成本利润按全部地块合计计算。

## 13. 作业工单（生成 → 快捷修改 → 完成/续药）

结果区点「🧾 生成工单」打开工单弹窗（与整体风格一致的简洁界面）：

- **汇总卡**：总水量、总趟数、预计总时长、药量（参考 → 实际可直接改）
- **续药提醒条**：剩余水量 ≈ 还需几套药（7舍8入）
- **逐地块行**：地块名 + 组号·水量·组趟数·每趟量 + 「已完成(升)」输入框
  （即时显示剩余量和剩余趟数）
- **农户名称 / 备注**：可填，随工单保存
- 点「📋 复制纯文本工单」生成完整纯文本（含逐地块数据、汇总与**农户结算**），
  可粘贴到微信/备忘录留存。已完成数据跨会话保留，适合分多次作业的续药场景。
- **农户结算单**：每农户一行四数据——地块大小(亩)、打药的钱(元)、用药量(套)、
  药钱(元)；**不包药自动隐藏后两项**。打药钱 = 农户档案单价 × 地块面积，
  药钱 = 用药量 × 一套药价（不扣库存）；作业方的补购量单独显示，两者解耦。

## 14. 作业时间估算（兑药调度模型）

「⏱️ 作业时间估算」按实际作业流程建模：

1. **首批兑水兑药串行在最前**——飞行必须等首批兑药完成
2. 然后进入「加药装载 → 飞行」循环；总水量超过「单批兑水量」时分多批，
   **第 2 批起与飞行并行**（利用升降、充电等待的地面空闲）
3. 总作业时间 = max(兑药总时长, 首批兑药 + 飞行阶段时长)
4. 加药装载时间是每循环的真实串行耗时，不能被飞行抵消（充电可以）——
   这就是装载时间"高优先级于充电时间"的含义

「🔋 电池循环状态图」的时间轴已平移到首批兑药完成之后，点击色块可看每趟/每循环详情。

## 常见问题

### Q: 数据会丢失吗？
A: 数据存在浏览器 LocalStorage 中。如清空浏览器缓存会丢失，请定期用「导出」备份重要配置。

### Q: 可以在多台设备同步吗？
A: 浏览器限制无法自动同步，但可以用「导出 → 发送 → 导入」手动同步。

### Q: 公式不适用我的用药类型怎么办？
A: 所有参数都能修改（点「✏️ 编辑当前」），或「＋ 新建类型」建一套自己的参数。

### Q: 可以添加自定义用药类型吗？
A: 可以，界面上「＋ 新建类型」即可，无需改代码。自定义类型会随配置导出分享。

## 15. 农户档案

顶栏「🧑‍🌾 农户档案」管理农户：新建/编辑/删除（有地块引用时其地块自动归入默认农户）、
启用勾选、按名称搜索。每个农户可设**默认每亩收费**，地块绑定农户时自动带出。

- 一个农户有多块分散地块：各自建地块卡，标相同**农户**即可在结算里合并
- 不同农户的地块相邻时：标相同**作业组**连片连续作业，账务仍按农户独立
- 旧版本工单里填过的农户名会自动转为档案

## 16. 数据口径速查

- **用药量（给农户看）**：小数两位，按地块面积精确归属
- **采购量（给自己备药）**：合计后 7舍8入 的整套装数
- **补购量**：采购量 − 现有库存（只影响自己的成本，不影响农户药钱）
- **作业组**：只影响怎么飞（趟数/时长）；**农户**：只影响怎么收钱——两者互不干扰

## 17. 界面布局与快捷操作（v4.2）

- **填写靠上**：用药类型 → 地块与作业组 → 作业参数 → 成本 → 时间参数，
  计算结果与时间估算可视化在下方（桌面端结果常驻右列）
- **高级设置**：机载装药上限、电池折旧、每亩棵数/每棵水量/一套药需水量/
  省药系数/飞行高度、各种折旧保险等低频字段收进各面板底部「⚙️ 高级设置」
  折叠区（默认收起，展开状态会记住）
- **数字步进**：所有数字输入带 −/+ 大按钮，按字段步长增减（每亩水量 ±1、
  省药系数 ±0.1、棵数 ±10…），长按可连发
- **农户快捷存/取**：地块卡绑定农户后出现 ⭐存为默认 / 📄读入——把当前
  地块尺寸存成该农户的默认值，下次一键读入；档案在顶栏 🧑‍🌾 卡片式管理

## 18. 类型推荐参数与棵数速算（v4.3）

- **选类型即套用**：点击「杀菌」自动套用 飞行高度 6米 / 航线间距 4米 / 飞行速度 2m/s；
  「果蝇」为 7米 / 6米 / 4m/s（覆盖当前时间参数，可再调）。自定义类型在编辑弹窗里
  也可设自己的推荐间距/速度
- **棵数速算药量**：类型面板里的独立小工具——农户不知道亩数、只说"我有 300 棵树"时，
  填棵数直接出建议药量（小数与采购取整）与折合亩数参考。纯参考计算，
  **不进入下方作业计算**（作业一律按地块亩数）
- **作业前提醒**：地块面板底部的固定提示卡（天气/温度/直晒/距离/电池），
  工单纯文本尾部也附带同样的作业前检查清单

## 19. 药量参考、加水口径与凑药（v4.4）

- **药量参考（四来源，类型面板下方卡片）**：
  1. 标准参考（按亩）——主计算需求，采购按它 7舍8入
  2. 标准参考（按棵）——填棵数即算（农户只知道棵数时）
  3. 农户标准——人工打药量（套/亩）× 省药系数 × 亩数（农户按自己
     人工习惯报量时用，可空）
  4. 实际/临时——工单「实际用药」手填，空回退按亩标准
  三来源互不覆盖：采购与成本按标准取整，结算药钱按实际
- **加水口径**：总加水 = 计算水量 + 富余水量（默认35升，管道/富余/留底）；
  兑药批次按总加水算；每批先留「抽药占用」（默认40升，按药种类20~60）
  的空间，兑药后看情况补满
- **凑药**：工单每农户可填「自备(套)」——农户自备药不足、我们补充卖出时，
  药钱只按补充量计（自备不收钱）；账单注明 自备+补充 明细

## 20. 充电次数手动覆盖与电池循环台账（v4.5）

- **充电次数（手动）**：时间参数面板，位于"单批兑水量"和"拥有电池数量"之间。
  - 填了（>0）：循环数、每次充电油钱按此值计算，结果显示"（手动）"，
    成本里的"单循环亩数"自动禁用
  - 不填或 0：按 总面积 ÷ 单循环亩数 估算（成本面板可改单循环亩数），
    结果显示"（参考：总面积÷X亩）"
  - v4.5 修复：此前"单循环亩数"从未参与计算（恒按趟数÷6），现已真正生效
- **电池循环台账**（时间参数下方独立面板，跨任务保存在本机）：
  1. **电池列表**：添加/删除电池，改名称；每块电池独立微调基础循环数
     （输入框直填或 ± 步进，长按连发）；空列表可按"拥有电池数量"一键创建
  2. **本次任务循环分配**：填任务循环总数（可点"⟳ 带入"取当前计算的
     充电次数，也可手动填），"平均分"一键均摊，逐块微调；
     顶部"剩余未分配"归零（显示 ✓）才能确认，防止多加漏加
  3. **确认加到电池**：累加到每块电池的基础循环数，并生成一条分配记录
     （时间/备注/每块加了多少）；**↩ 回滚**整笔恢复到分配前数值
  4. 台账随"导出配置"一起导出（只导出当前循环数，分配记录不迁移）
