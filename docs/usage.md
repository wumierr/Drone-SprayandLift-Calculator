# 📖 详细使用说明

## 1. 选择用药类型

主界面左侧「🧪 用药类型」面板点击类型卡片即可。内置「杀菌」「果蝇」两种，可自定义增减：
- **＋ 新建类型**：填写名称/图标/每亩水量/一套药需水量/省药系数等，保存后立即可用
- **✏️ 编辑当前**：修改选中类型的参数
- **↺ 找回默认**：一键找回被删除的杀菌/果蝇
- 选中类型后自动加载：建议飞行高度、每亩水量、每亩棵数 & 每棵水量、一套药需水量、省药系数
- 旧版本存的作物（果树/水稻等）会自动转为自定义类型，参数不丢
- 自定义类型随「导出配置」一起分享，别人导入即得

下方会显示该类型的作业注意事项。

## 2. 设置作业参数

「📋 作业参数」面板中可修改：
- **计算基准**：按亩数 / 按棵数（仅单地块模式）。按棵数直接填果树棵数，亩数按 棵数÷每亩棵数 反推；多地块模式固定按亩数填写
- **果树棵数**：按棵数计算时的主输入
- **作业亩数**：本次需要打药的总亩数（按棵数计算时由棵数反推，输入框自动隐藏）
- **机载装药上限**：无人机药箱一次最多装载的药液量（多地块模式按此算每块地最少趟数）
- **地块模式**：单地块 / 多地块（多地块见第 12 节）
- **飞行高度**：可使用类型默认值，也可根据实际情况调整
- **每亩水量**：根据作物密度和生长期调整
- **每亩棵数 / 每棵水量**：果树类使用；按棵数计算时每亩棵数锁定只读
- **一套药需水量**：决定一套药能配多少药液
- **无人机省药系数**：0.7 表示比人工省 30%，可根据机型调整

> 💡 鼠标悬停字段名右边的 **`i`** 图标可查看该参数的详细说明。

## 3. 设置成本参数

「💰 成本明细」面板按 4 个 Tab 分类：

### 🔋 循环成本
- **单次循环成本**：一个循环（一组电池）的电池折旧+充电+油钱总和（默认 7 元）
- **三相电循环成本**：使用三相电时仅需电池折旧（默认 5 元）
- **单循环亩数**：一组电池能完成的亩数（默认 2 亩）
- **使用三相电**：勾选后切换为三相电模式

### 🚚 交通
- **单程路程**：驻地到地块的距离
- **满载油耗**：小型厢式货车满载（无人机+发电机+水桶+人员）的油耗，建议 10-14 升/100km
- **油价**：当前油价
- **路桥费**：来回过路费总和
- **车辆折旧**：每公里分摊，建议 0.3-0.6 元

### 👥 人工
- **作业人数**：含飞手、配药、搬运
- **作业天数**：本次作业天数
- **每人日薪**：工钱
- **每人每天餐费**：含中午工作餐
- **住宿费**：若需在外住宿的总住宿费/天

### 📦 其他
- **一套药剂价格**：药剂进货价
- **无人机折旧**：每亩分摊
- **维修保养储备**：桨叶、电机等易损件
- **防护装备**：口罩、手套等每次分摊
- **清洗费用**：作业后清洗药箱
- **保险分摊**：每亩分摊
- **其他杂费**：通信、停车等

## 4. 设置收入

「💵 收入与药剂」面板：
- **每亩收费**：服务费单价
- **农机补贴等**：如有补贴填入

## 5. 查看结果

右侧「📊 计算结果」面板实时显示：
- 💊 药剂用量（套，含向上取整建议）
- 💧 用水量（升）
- 💰 总成本（含每亩成本）
- 📈 粗略利润（含利润率，亏损红色警示）

下方还有：
- 🚁 建议飞行高度
- 🔄 需要循环数
- 📐 每亩成本
- 💵 每亩利润

「🧮 成本汇总」表展示各成本项金额及占比条形图。

## 6. 计算按钮（触发动画）

点击「🚁 开始计算」按钮：
- 触发无人机带着药雾飞过屏幕的动画
- 把本次计算保存到历史记录
- 显示「计算完成」提示

## 7. 预设管理

### 保存预设
点击「💾 存为预设」，输入名称（如「苹果园-春季-10亩」）即可。

### 加载预设
点击「📂 加载预设」打开预设管理弹窗：
- 点击列表项加载
- **右键**点击列表项可删除

### 预设内容
预设保存当前用药类型、作业参数、所有成本和收入参数的完整快照。

## 8. 导入导出（配置分享）

### 导出
1. 点击「📤 导出」按钮
2. 切换 **📝 文本格式**（易读，带中文标记）或 **⚙️ JSON 格式**（精确）
3. 点击「📋 复制到剪贴板」
4. 发给朋友（微信、QQ、邮件均可）

### 导入
**方式 A：通过弹窗**
1. 点击「📥 导入」按钮
2. 粘贴配置文本
3. 点击「识别并填入」

**方式 B：快捷键**
- 按 `Ctrl+Shift+V`（Win）或 `Cmd+Shift+V`（Mac）直接从剪贴板读取并填入

### 支持的格式
- ✅ JSON 格式（导出时的 JSON 选项）
- ✅ 文本格式（导出时的文本选项，带【】标记）
- ✅ 自动识别，无需手动指定

## 9. 历史记录

点击「🕘 历史记录」按钮查看最近 20 次计算。
可点击「🗑 清空历史」一键清除。

## 10. 主题切换

点击右上角「☀️ / 🌙」按钮切换日间/夜间模式，自动记忆。

## 11. 打印结算单

按 `Ctrl+P` 触发浏览器打印，会自动隐藏装饰元素，生成干净的结算单（可直接打印或保存为 PDF）。

## 12. 多地块模式

「📋 作业参数」面板顶部切换「单地块 / 多地块」。多地块模式下每个地块一张卡片：

- **地块名称**：自定义（默认 地块1、地块2…）
- **亩数**：该地块打药面积（多地块固定按亩数，与棵数无关）
- **转场时间**（分钟）：加药点到该地块的单程时间；可用「全部地块转场：近·3分 / 中·5分 / 远·8分」一键设置，选「远」= 多留余量
- **趟数（选填）**：留空 = 按机载装药上限自动算最少趟数；手动填写可凑实际每趟加药量（每趟加药量 = 地块水量 ÷ 趟数，改趟数即时重算）
- 卡片底部实时显示该地块：水量 / 最少趟 / 每趟量

结果区自动生成**地块明细表**（水量/最少趟/趟数/每趟量/转场/药量 + 合计行），
汇总与成本利润按全部地块合计计算。

## 13. 作业工单（生成 → 快捷修改 → 完成/续药）

结果区点「🧾 生成工单」打开工单弹窗（与整体风格一致的简洁界面）：

- **汇总卡**：总水量、总趟数、预计总时长、药量（参考 → 实际可直接改）
- **续药提醒条**：剩余水量 ≈ 还需几套药（7舍8入）
- **逐地块行**：地块名 + 水量·趟数·每趟量·转场 + 「已完成(升)」输入框
  （即时显示剩余量和剩余趟数）；单地块模式为总已完成水量
- **农户名称 / 备注**：可填，随工单保存
- 点「📋 复制纯文本工单」生成完整纯文本（含逐地块数据与汇总），可粘贴到
  微信/备忘录留存。已完成数据跨会话保留，适合分多次作业的续药场景。

## 14. 作业时间估算（兑药调度模型）

「⏱️ 作业时间估算」按实际作业流程建模：

1. **首批兑水兑药串行在最前**——飞行必须等首批兑药完成
2. 然后进入「加药装载 → 飞行」循环；总水量超过「单批兑水量」时分多批，
   **第 2 批起与飞行并行**（利用升降、充电等待的地面空闲）
3. 总作业时间 = max(兑药总时长, 首批兑药 + 飞行阶段时长)
4. 加药装载时间是每循环的真实串行耗时，不能被飞行抵消（充电可以）——
   这就是装载时间"高优先级于充电时间"的含义

「🔋 电池循环状态图」的时间轴已平移到首批兑药完成之后，点击色块可看每趟/每循环详情。

## 常见问题

### Q: 数据会丢失吗？
A: 数据存在浏览器 LocalStorage 中。如清空浏览器缓存会丢失，请定期用「导出」备份重要配置。

### Q: 可以在多台设备同步吗？
A: 浏览器限制无法自动同步，但可以用「导出 → 发送 → 导入」手动同步。

### Q: 公式不适用我的用药类型怎么办？
A: 所有参数都能修改（点「✏️ 编辑当前」），或「＋ 新建类型」建一套自己的参数。

### Q: 可以添加自定义用药类型吗？
A: 可以，界面上「＋ 新建类型」即可，无需改代码。自定义类型会随配置导出分享。
