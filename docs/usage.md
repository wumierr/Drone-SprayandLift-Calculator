# 📖 详细使用说明

## 1. 选择植物

主界面左侧「🌱 植物选择」面板中点击对应植物卡片即可。选中后会自动加载该植物的：
- 建议飞行高度
- 每亩水量
- 每亩棵数 & 每棵水量（果树类）
- 一套药需水量
- 无人机省药系数

下方会显示该植物的作业注意事项（如花期慎用、安全间隔期等）。

## 2. 设置作业参数

「📋 作业参数」面板中可修改：
- **作业亩数**：本次需要打药的总亩数
- **飞行高度**：可使用植物默认值，也可根据实际情况调整
- **每亩水量**：根据作物密度和生长期调整
- **每亩棵数 / 每棵水量**：仅果树类使用，面积类可填 0
- **一套药需水量**：决定一套药能配多少药液
- **无人机省药系数**：0.7 表示比人工省 30%，可根据机型调整

> 💡 鼠标悬停字段名右边的 **`i`** 图标可查看该参数的详细说明。

## 3. 设置成本参数

「💰 成本明细」面板按 4 个 Tab 分类：

### 🔋 循环成本
- **单次循环成本**：一个循环（一组电池）的电池折旧+充电+油钱总和（默认 7 元）
- **三相电循环成本**：使用三相电时仅需电池折旧（默认 5 元）
- **单循环亩数**：一组电池能完成的亩数（默认 2 亩）
- **使用三相电**：勾选后切换为三相电模式

### 🚚 交通
- **单程路程**：驻地到地块的距离
- **满载油耗**：小型厢式货车满载（无人机+发电机+水桶+人员）的油耗，建议 10-14 升/100km
- **油价**：当前油价
- **路桥费**：来回过路费总和
- **车辆折旧**：每公里分摊，建议 0.3-0.6 元

### 👥 人工
- **作业人数**：含飞手、配药、搬运
- **作业天数**：本次作业天数
- **每人日薪**：工钱
- **每人每天餐费**：含中午工作餐
- **住宿费**：若需在外住宿的总住宿费/天

### 📦 其他
- **一套药剂价格**：药剂进货价
- **无人机折旧**：每亩分摊
- **维修保养储备**：桨叶、电机等易损件
- **防护装备**：口罩、手套等每次分摊
- **清洗费用**：作业后清洗药箱
- **保险分摊**：每亩分摊
- **其他杂费**：通信、停车等

## 4. 设置收入

「💵 收入与药剂」面板：
- **每亩收费**：服务费单价
- **农机补贴等**：如有补贴填入

## 5. 查看结果

右侧「📊 计算结果」面板实时显示：
- 💊 药剂用量（套，含向上取整建议）
- 💧 用水量（升）
- 💰 总成本（含每亩成本）
- 📈 粗略利润（含利润率，亏损红色警示）

下方还有：
- 🚁 建议飞行高度
- 🔄 需要循环数
- 📐 每亩成本
- 💵 每亩利润

「🧮 成本汇总」表展示各成本项金额及占比条形图。

## 6. 计算按钮（触发动画）

点击「🚁 开始计算」按钮：
- 触发无人机带着药雾飞过屏幕的动画
- 把本次计算保存到历史记录
- 显示「计算完成」提示

## 7. 预设管理

### 保存预设
点击「💾 存为预设」，输入名称（如「苹果园-春季-10亩」）即可。

### 加载预设
点击「📂 加载预设」打开预设管理弹窗：
- 点击列表项加载
- **右键**点击列表项可删除

### 预设内容
预设保存当前植物、作业参数、所有成本和收入参数的完整快照。

## 8. 导入导出（配置分享）

### 导出
1. 点击「📤 导出」按钮
2. 切换 **📝 文本格式**（易读，带中文标记）或 **⚙️ JSON 格式**（精确）
3. 点击「📋 复制到剪贴板」
4. 发给朋友（微信、QQ、邮件均可）

### 导入
**方式 A：通过弹窗**
1. 点击「📥 导入」按钮
2. 粘贴配置文本
3. 点击「识别并填入」

**方式 B：快捷键**
- 按 `Ctrl+Shift+V`（Win）或 `Cmd+Shift+V`（Mac）直接从剪贴板读取并填入

### 支持的格式
- ✅ JSON 格式（导出时的 JSON 选项）
- ✅ 文本格式（导出时的文本选项，带【】标记）
- ✅ 自动识别，无需手动指定

## 9. 历史记录

点击「🕘 历史记录」按钮查看最近 20 次计算。
可点击「🗑 清空历史」一键清除。

## 10. 主题切换

点击右上角「☀️ / 🌙」按钮切换日间/夜间模式，自动记忆。

## 11. 打印结算单

按 `Ctrl+P` 触发浏览器打印，会自动隐藏装饰元素，生成干净的结算单（可直接打印或保存为 PDF）。

## 常见问题

### Q: 数据会丢失吗？
A: 数据存在浏览器 LocalStorage 中。如清空浏览器缓存会丢失，请定期用「导出」备份重要配置。

### Q: 可以在多台设备同步吗？
A: 浏览器限制无法自动同步，但可以用「导出 → 发送 → 导入」手动同步。

### Q: 公式不适用我的作物怎么办？
A: 所有参数都能修改，选最接近的作物作为模板，然后调整数值。或保存为预设下次直接用。

### Q: 可以添加自定义作物吗？
A: 可以，编辑 `js/data.js` 中 `PLANT_DATABASE` 即可，详见 [README.md](../README.md#自定义扩展)。
